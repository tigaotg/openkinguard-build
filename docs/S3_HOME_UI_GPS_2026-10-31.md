# OpenKinGuard 0.5.2：主页、定位自检与低配性能修订（2026-10-31）

## 用户反馈与实现

1. **按设备指纹显示**：同一设备同时是救助者和被救助者时，主页只渲染一张设备卡，同时显示“请求对方位置”和“向对方报平安”。不会以昵称或关系ID作为设备身份。
2. **在线设备优先**：仅在最近通过签名验证且对应局域网或自建中继连接可用时，主页展示在线卡。其他卡默认隐藏于“展开离线设备”下；展开也只列名称、最近验签时间和设置入口说明，不提供假在线的操作按钮。即使对方实际上刚刚上线但心跳尚未验签，也不会贸然标为在线。
3. **定位时间**：每张在线被救助设备卡显示本次定位查询的发起时间，以及最近一条已验签定位的采集时间，采用“10秒前/30秒前/1分钟前/5分钟前”等相对标记，较旧的位置明确标注历史位置，点击地图时仍有旧坐标确认弹窗。
4. **GPS 本机诊断**：设置首页和“设备与授权”中都可点击“检测本机GPS及当前位置”。检查精确/模糊权限、系统 GPS/网络提供者是否开启，并在前台最多等待10秒获取可靠位置。报告经纬度、采集时间、估计精度和提供者来源；网络定位绝不冒充卫星 GPS，缺权限或无位置时给出具体原因。诊断坐标仅显示在本机，不发送或自动保存进远程定位历史。
5. **降低老手机开销**：原先每次 Compose UI 刷新都读取并用 Android Keystore 解密本机整份历史。现在进程内所有 S1CaseStore 实例共享一个内存快照；变更时仍先完成原子加密文件写入再更新内存，所以不改变加密位置、密钥或持久化格式。减少无关主界面文本和离线卡片绘制，复杂按键说明移入设置可展开帮助。

## 明确不变的安全边界

- GPS 单次远程查询依旧需要已绑定的正确救助关系、对端用户授权、对端前台及 Android 定位权限；本机自检不授予任何远程查看权限。
- 未修改公钥指纹、会话签名、129项需求原件、数据保留策略、多中继默认关闭策略。
- “在线”仅表示最近完成签名通信，不保证后台实时在线；新位置的时间是**采集时间**，不是对方现在的位置。
- 荣耀 7X 卡顿的原因之一有明确代码证据（反复解密），此次进行了针对性优化，但无法在未连接的真实设备上承诺帧率、续航或完全消除卡顿。
- 本次尚无 Android 10 / Android 17 真实设备回归或公网实测，不可用于真实急救。
