# OpenKinGuard 0.5.4：中国大陆网络探针筛选的公共节点候选

## 核心变化

- 继续使用 0.5.3 的 Nostr 端到端加密适配器，不修改旧设备签名密钥、扫码帮助关系、位置权限或核心决策层。
- 默认推荐三条：`wss://relay.nostr.net`、`wss://relay.nostr.info`、`wss://relay.nostr.wirednet.jp`。
- 设置提供另一组备用方案：前两条不变，第三条替换为 `wss://relay.kizuna-miki.com`。
- 维持用户此前确定的「同时最多 3 个 WSS 公共节点」限制；不会因为添加推荐候选就连接第 4 个节点。
- 只有保存的地址**完全等于** 0.5.3 初始示例（`relay.primal.net` 和 `nos.lol`）才自动替换；自定义列表不覆盖。
- 默认仍是关闭公网节点。填写候选后需明确点击“开启公共通信”；两台手机必须至少共享一个可用节点。

## 2026-10-31 抽检结果

以 Globalping 的中国大陆公开探针（本次分布在北京、深圳、广州，主要是腾讯与阿里云数据中心）对各节点进行 **HTTPS 请求与 TLS 握手**。这不是移动运营商、不是 WebSocket 升级请求，也不是事件发布与订阅验收。

| 节点 | 中国大陆 HTTPS 成功数 / 3 | 处理方式 |
|---|---:|---|
| relay.nostr.net | 3/3 | 作为默认候选 |
| relay.nostr.info | 3/3 | 作为默认候选 |
| relay.nostr.wirednet.jp | 2/3 | 作为默认候选，存在区域失败 |
| relay.kizuna-miki.com | 2/3 | 供用户主动切换的备用节点 |
| relay.nostrzh.org | 3/3 | 中文社区邀请/写入白名单，**不作通用节点** |
| relay.primal.net | 0/3 | 从内置默认移除 |
| nos.lol | 0/3 | 从内置默认移除 |
| relay.damus.io | 0/3 | 不推荐给大陆默认配置 |
| nostr21.com | 0/3 | 另有 NIP-11 `payment_required`，不推荐 |
| nostr.mom | 0/3 | 不推荐给大陆默认配置 |
| nostr.shawnyeager.net | 0/3 | 不推荐给大陆默认配置 |

前三个默认节点及备用的 Kizuna 节点均在检查环境返回 HTTP 200 的 NIP-11 服务信息、声明 NIP-01，并且当次没有声明强制付费。但**没有进行实际 NIP-78 kind30078 的读写验收**，中继仍可能拒收本应用消息。

## 不能过度宣传的地方

1. 大陆云机测通 ≠ 中国电信/中国移动/中国联通手机可用 ≠ 长期连续在线。
2. 网络条件与中继运营策略会变化，结果仅表示某一时刻抽检情况，不作为永久许可或 SLA。
3. 公共中继可以看到设备指纹及连接元数据；业务正文仍做端到端加密与原设备密钥签名验证。
4. 中继 WebSocket 已连接、或者 Nostr `OK` 都不代表 SOS 已到达对方手机；必须收到设备签名回执。
5. App 被系统后台冻结或强制停止时，公共节点无法保证唤醒手机。不得依赖预览版保障人身安全。

## 设备升级与回归

- 新版 Android `versionCode=25`，仍为原 `io.github.tigaotg.openkinguard.debug.s1diagnostic` 应用及相同签名证书。
- 新增单元测试覆盖三节点默认、备用三节点、最多三节点和旧版默认配置迁移时不覆盖自定义列表。
- 仍需用用户的 Android 10 荣耀 7X 与 Android 17 手机分别在家宽、手机蜂窝网上进行 WSS 真机收发、签名回执、GPS 与 SOS 模拟测试。
