# OpenKinGuard S3 GPS 定位阶段交接（2026-10-31）

## 本轮范围

- 客户端 `0.4.0-s3-encrypted-location`，`versionCode=15`，`minSdk=29`（Android 10 起），沿用已经安装的 `s1diagnostic` 应用 ID 和原调试签名；不删除旧帮助关系和密钥。
- 在单一 APK 中保持每台设备可同时作为帮助者或被帮助者；定位授权按**关系方向**独立，默认关闭。
- 直接使用 Android `LocationManager`，GPS 或网络定位，不需要 Google 服务/中央账号；系统只允许大致位置时应接受网络定位，显示实际精度。
- Android 10+ 只申请 `ACCESS_COARSE_LOCATION`/`ACCESS_FINE_LOCATION` 前台定位权限；**不申请后台定位权限**，也不伪装为紧急情况绕过系统权限。

## 工作流程

1. 在“我的设备 → 我的定位”中主动申请系统定位权限；也可单独查看本机当前位置（不会发给对方）。
2. 被帮助者在指定救助关系下按“授权救助者查看定位”；可以随时撤销。其他救助关系不因此获得授权。
3. 救助者与对方保持局域网认证连接，按“请求一次定位”或“连续查看（约每10秒请求）”。双方的 App 必须处于前台。
4. 发送已签名 `OKG_S3_LOCATION_REQUEST_V1`，包含关系 ID、事件 ID 和本次临时加密公钥；对方核查原有签名/方向/防重放窗口、系统权限、授权、前台状态。
5. 对方只对已授权请求采集近期定位，先核实精度和采集时效，再以临时 P-256 ECDH、HKDF-SHA256、AES-256-GCM 加密坐标，发送签名 `OKG_S3_LOCATION_RESULT_V1`。拒绝时发送已签名 `OKG_S3_LOCATION_DENIED_V1`，不带坐标。
6. 救助者核查签名、关系、事件 ID、响应关联请求 ID、时效和 AES-GCM 完整性，随后在本机展示并加密保存经纬度、精度、真实采集时间及设备指纹。
7. “记录 → 定位”可查看本机留存的位置、手动导出 GPX 或单独清除定位记录。JSON 历史导出亦包含精确坐标，界面明确告知导出文件是明文。

## 数据安全和隐私边界

- 发送请求不代表有权获得坐标；受保护设备的主人需要在操作系统和应用内**双重授权**。
- 每次请求生成临时 EC 密钥，私钥只存在于发起请求进程的此次调用中。AES-GCM 的认证关联数据绑定关系、事件和请求编号；位置不是靠纯签名明文传输。
- 收到新位置前应检查位置年龄（至多60秒）及未来时间容差（至多30秒），超时结果拒绝按实时坐标展示；系统内部复用的缓存位置不超过30秒。
- 位置精度不保证是 GPS 级：网络定位或 Android 12+ 近似权限可能返回误差较大的坐标；界面须始终展示精度和采集时间。
- 收件方的坐标以当前 Android Keystore AES-GCM 历史加密存放，最多200条且受7/30/90天保留选项限制。用户主动导出的 JSON/GPX 是明文，分享之前须自行确认。
- 进入后台、失联、无 GPS、未开启定位、权限被禁用都可能导致定位失败；**不可保证后台每10秒定位**。原 S2 局域网监听服务不等于后台定位权限。
- 被帮助者撤销应用内授权时会再次在发出位置前检查授权（防止采集中途撤权之后泄露）。已接收方以前保存的位置不会因此自动删除；需要由其本人清除。
- GPS 不影响 SOS 触发、签名、接手或结案；没有位置数据不代表被帮助者安全或不安全。

## 当前仍未实现与下一步

- 尚未实现公网跨网络中继、端到端加密中继传输、后台低功耗动态采集、紧急模式高频采集、地图内嵌 MapLibre 和离线地图、地理围栏、GPS 随 SOS 事件自动附加、跨端轨迹同步与权限审计 UI。
- 目前的“连续查看”是前台主动重复查询，不是可在锁屏/关屏/无人操作时长期可靠运行的后台轨迹服务。
- 真机安装和两设备定位功能的最终验收由用户推迟，暂不声称 Android 10 / 17 设备 GPS、耗电或大致定位已通过实测。
- 待测试阶段检查：系统权限（仅大致/精确/拒绝）、不同权限组合、对方未授权和撤权、进入后台暂停、断网、设备时钟异常、GPS精度和采集年龄、签名防重放、升级保留旧关系。

## 构建及检验

构建命令：

```bash
./gradlew :security:protocol:test :core:engine:test :adapters:mock:test :app:assembleDebug :app:lintDebug
```

协议的 JVM 测试覆盖位置报文格式、非法位置数值、拒绝响应、签名封包、临时 ECDH+AES-GCM 加/解密、错误私钥、篡改密文和事件ID不可混淆。Android 的 `LocationManager` 硬件行为必须由真机验收。

以上功能是 S3 定位基础增量，并不代表129项总需求已完成。**当前版本不得用于实际救援。**
