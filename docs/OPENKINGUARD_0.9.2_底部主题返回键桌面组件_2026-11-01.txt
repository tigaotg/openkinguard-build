OpenKinGuard 0.9.2 Android 更新与真机测试交接
日期：2026-11-01
包名：io.github.tigaotg.openkinguard.debug.healthpilot
versionCode：37
versionName：0.9.2-widgets-back-theme-standalone
最低 Android 10；不强制依赖谷歌服务。

一、按本次反馈完成的改动

1. 底部「求助/设备/设置」导航栏使用主题的配色容器（surfaceContainerLow）及选中态颜色，非黑色主题不再固定保持原来的底栏颜色。
2. Material 3 的 primaryContainer、secondaryContainer、surfaceContainer 等从 JSON 主题色统一派生，使其他色板也能影响底栏和选中背景。
3. Android 10～14 的系统三键导航栏尝试随主题调整背景与明暗图标；Android 15+ 手势导航区域由系统最终控制，应用不能保证任何桌面/ROM都完全同色。
4. 系统返回键：设置详细页→设置分类；普通二级页面→上一来源页；无历史的独立页面→首页；首页短时间连续按两次才退出。确认对话框优先关闭，不直接退出。
5. 新增两种原生 Android 桌面小组件：
   A.「家人在线状态」：显示最近经过身份验签在线的设备数量、最多三个家人昵称及最近检查时间，并附 SOS / 我已安全按钮。
   B.「SOS与报平安」：适合较小桌面的双按钮快捷组件。
6. 小组件按钮只打开 App 中的对应确认对话框，由使用者二次确认才创建演练 SOS 或报平安；不会由桌面静默发送，也不会自动拨号或发送收费短信。
7. 新增设置 → 桌面小组件：支持在系统桌面允许时请求钉到桌面，不支持时提供长按桌面添加的文字指导。
8. 小组件在线判断延续 APP 的安全原则：只有已验证通信关系、当前有效签名会话和近期签名心跳，才显示在线。不借助未认证 BLE 设备名、广播或未经验证的节点显示在线。
9. 状态可能不实时，组件显式标注状态检查时间。未运行后台监听、状态过期、无数据时显示“待验证”。不把显示组件当成可靠生命体征监测。
10. 小组件昵称仅在 APP 进程内存中缓存，不将敏感关系、电话号码、蓝牙地址、精确坐标、心率写进新的明文持久化缓存。

二、如何添加小组件（一个手机即可测试）

方式 A：打开 APP → 设置 → 桌面小组件 → 选择“添加状态小组件到桌面”或“添加快捷小组件到桌面” → 系统桌面弹框确认。
方式 B：桌面空白处长按 → 小组件/窗口小工具 → OpenKinGuard → 选择对应组件 → 添加。

三、回归测试清单

1. 依次切换“经典紫/森林绿/暖阳橙/深夜守护”，观察底部大导航栏、选中图标与文字颜色有没有变化。
2. 设置 → 桌面小组件 → 添加两种尺寸。返回桌面，确认有组件标题及按钮。
3. 无另一台手机时，应显示“在线状态待验证”或“暂无已验签在线设备”；不要凭空显示假昵称。
4. 点击组件“测试 SOS” → APP 应出现确认窗口；点击取消，不产生求助事件。
5. 点击组件“我已安全” → APP 应出现确认窗口；点击取消，不产生报平安事件。
6. 手动按确认，检查是否只创建测试记录；不因按钮文字误认真实急救已经送达。
7. App 内进入设置 → 日常使用与设备自检 → 按系统返回键，应退回设置分类。
8. 设置 → 主题与外观 → 返回，应退回设置分类；设置分类 → 系统返回键，应退回先前主页面。
9. 回到首页后单按返回键，应提示“再按一次”；2秒内再按一次才退出。
10. 启用/停止用户主动开启的持续监听，检查小组件状态是否变化；在手机睡眠和重启后仍需手动检查刷新情况。
11. 以后找回第二台手机，测试昵称、在线数、验签心跳时效及两个快捷按钮的双机签名回执。

四、尚未完成且不能保证的能力
- 没有对真实手机桌面或第二台手机做过本版现场验证；Android 不同厂商的桌面、锁屏和省电限制各异。
- Android 桌面定时更新受系统调度限制，30分钟周期不是高频实时刷新保障；打开前台应用和用户主动启用的服务可提供较新的状态。
- 本版小组件的 SOS 仍为演练，不是可靠救援报警。跨移动网络 P2P、后台心率异常自动向家属求救及自动电话短信尚未完成。
- 部分旧版独立测试包的应用 ID 或签名不同，不可把覆盖升级误认为自动迁移历史身份。
