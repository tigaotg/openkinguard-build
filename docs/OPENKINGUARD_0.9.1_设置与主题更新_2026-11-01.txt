OpenKinGuard 0.9.1 设置分类与社区主题更新说明
日期：2026-11-01

一、改动
1. 设置首页不再连续展示所有开关、账号、联系人和长篇诊断。
2. 设置分类独立：新手引导、日常自检、公共节点、私人中继、地图、后台、通知、厂商查找、病历、历史保留、联系人、高级信息、主题与外观。
3. 点击一项后进入独立内容页，点“返回设置分类”回到目录；进入时自动滚到顶部。
4. 分类页可按名称搜索，不需要在很长的页面反复上下滑动。
5. 新增主题：内置经典紫、深夜守护、森林绿、暖阳橙、高对比黑白共五种。
6. 允许从本地 JSON 导入、更新、选择、导出和删除社区主题；强制记录作者与许可。
7. 主题只影响颜色，不会运行外部脚本或读取敏感数据，所选主题持久保存。

二、兼容性
继续支持 Android 10+，保留一个 APP 既可救助别人又可被救助的设计。
独立诊断包 ID：io.github.tigaotg.openkinguard.debug.healthpilot。
构建版本：versionCode 36，versionName 0.9.1-settings-themes-standalone。
可使用上一个 0.9.0-health-pilot-standalone 的相同开发签名进行覆盖升级。
其他早期预览版包名/签名与此不同，不能把安装结果当成直接升级。

三、如何测试（不需要手表，也不需要第二台手机）
1. 打开“设置”，确认首页只有分类名单、搜索框，没有展开十几个模块的正文。
2. 进入“日常使用与设备自检”，检查功能和返回按钮。
3. 依次进入“通知与提醒”“历史保留”“手动联系人”等页面，确认各功能仍可点。
4. 在主题页选择“森林绿”“深夜守护”，观察底部栏、按钮、卡片等是否改色。
5. 完全关闭 App 重新打开，确认主题保持。
6. 导出主题 JSON，用记事本改 id、name、author 并导入，确认可识别和切换。
7. 测试异常文件：错误 JSON、缺 author、颜色不符合 #RRGGBB，应显示失败而非崩溃。
8. 后续找回手表和另一部手机，再做蓝牙测量、公网联络和 SOS 双机验证。

四、安全与已知限制
这是开发测试版，不代替急救渠道。
跨移动网络的直连业务、后台健康报警、自动电话短信仍未完成。
主题目前仅支持浅色/深色及四种颜色，暂不支持更换页面布局或安装任意程序。
主题的颜色对比度仍需人工检查，尤其是老年人使用时。
手表和第二台手机不在场，故本版不声称完成这两项真机回归验证。

五、已有开源技术与归属
- Android Open Source Project (AOSP) / Google 与 Android 社区：Android 平台与系统能力。
- Jetpack Compose / AndroidX / Google：用户界面框架；Material 3 由 Google Material Design 项目维护。
- Kotlin / JetBrains 与贡献者：编程语言及编译工具。
- Gradle / Gradle Inc. 与贡献者：Android 构建系统。
- org.json (Android 平台自带 JSON 解析实现)：主题文件读取，不引入可执行插件。
