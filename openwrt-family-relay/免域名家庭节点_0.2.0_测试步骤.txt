OpenKinGuard 免域名家庭节点 0.2.0（第一阶段验证包）
日期：2026-11-01

一、这次真正完成的内容
1. OpenWrt 中继可生成独立 P-256 TLS 私钥和自签名证书。
2. 对证书计算 SHA-256(SPKI DER) 的64位十六进制节点指纹。
3. 命令再次运行只读取现有证书，不会悄悄替换私钥造成断联。
4. 尝试识别 wan_6 / wan6 的公网 IPv6，输出完整的 WSS 地址。
5. 新版独立 Android 测试客户端支持 #spki= 指纹固定模式，且仍允许旧式可信证书 WSS。
6. 节点公钥指纹不正确时握手失败；不会降级为明文 ws://。
7. 原来的白名单、设备签名认证、RAM 队列和流量限制均保留。

二、这次还没实现的内容
- 路由器安装不意味着手机已经能从移动网络访问！WAN 防火墙规则没有改。
- IPv6 地址会变，当前仍需在客户端手动更新；动态发现留待下一阶段。
- 手机移动网络可能只有 IPv4，无法直连只具有 IPv6 的家庭节点。
- 还未提供“扫描节点二维码后自动导入”的 UI；先复制完整地址测试。
- SOS/报平安的一部分旧业务帧仍未端到端加密；仅限信任的家庭节点。
- Android 测试版采用独立 applicationId 和开发密钥，不能覆盖之前安装的正式或诊断版。

三、在 OpenWrt 上安装新版本（先不要开放端口）
Windows PowerShell 在解压的目录父目录运行（替换路由器 LAN IP）：
    scp -r .\openwrt-family-relay root@192.168.2.1:/tmp/

SSH 到路由器：
    sh /tmp/openwrt-family-relay/install-on-openwrt.sh --check
    sh /tmp/openwrt-family-relay/install-on-openwrt.sh --install
    sh /tmp/openwrt-family-relay/install-on-openwrt.sh --setup-no-domain

第三条生成本机身份并输出：
    wss://[路由器公网IPv6]:9443/relay#spki=<64位节点公钥指纹>

私钥位于 /etc/ssl/openkinguard/privkey.pem；绝不要复制到手机或发给他人。

四、在两台手机上
安装本交付包的独立测试版，完成新的设备互相绑定；独立版本不会继承之前的绑定数据。
找到「设置 → 公网通信 → 私人中继」，两台都输入同一个完整的地址，含 #spki= 指纹。
先核对手机看到的完整指纹与 SSH 本地生成的指纹一致。
在 LuCI → 服务 → OpenKinGuard 家庭中继添加两台新测试 App 的设备指纹。
在确认无误后才选择启用服务。

五、第一轮只做 LAN 连接验证
先在同一 Wi-Fi 内测试；只有握手正常，再单独诊断公网 IPv6 和端口 9443。
请不要顺手开放路由器管理端口 80/443 或 SSH 22。
切记：'节点在线' 不等于 SOS 已经被对方收到，必须确认设备签名回执。

六、如何恢复关闭状态
LuCI → 服务 → OpenKinGuard 家庭中继，取消「启用私人中继」，保存并应用。
本版本安装或生成身份都不会自动打开 WAN 防火墙。

七、技术说明
TLS 由用户自行在安全通道核对的 SPKI 指纹建立信任，指纹是公开的，私钥保密。
此机制不能使用未修改的浏览器、旧版 OpenKinGuard 或其他普通 WSS 客户端；
这是与系统 CA 信任并列的“显式信任一个节点公钥”模式，不是关闭 TLS 校验。
